pve-tools

Signed apt repository for pve-tools, add-ons for Proxmox VE 8 and 9.

Packages

pve-console-log Persistent console scrollback for VM serial and CT consoles, replayed when you open the console in the web GUI.
pve-mods Meliox/PVE-mods web UI mods (node sensors, GPU, UPS, storage health, no-nag), built from the fork Msprg/PVE-mods. PVE 9.0+.

Add the repository

On each node, as root:

curl -fsSL https://msprg.github.io/pve-tools/pve-tools-archive-keyring.gpg \
    -o /usr/share/keyrings/pve-tools-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/pve-tools-archive-keyring.gpg] https://msprg.github.io/pve-tools stable main" \
    > /etc/apt/sources.list.d/pve-tools.list
apt update
apt install pve-console-log

Signing key

Fingerprint 46FC 63EC 1284 85C8 DB89 25B5 90B9 F73A 6B83 0C5F (ASCII-armored, binary keyring). Check it with gpg --show-keys /usr/share/keyrings/pve-tools-archive-keyring.gpg.
